
## 📝 Description

Un script local Tampermonkey qui ajoute une couche d'ajustements de confort, de petites automatisations sur [wiki-masters.com](https://www.wiki-masters.com).

## 🚀 Installation

1. Installez [Tampermonkey](https://www.tampermonkey.net/) (ou un gestionnaire de scripts local compatible) dans votre navigateur
2. Ouvrez le tableau de bord de Tampermonkey et créez un nouveau script
3. Collez le contenu de [`wiki-masterbetter-tags.me.js`](./wiki-masterbetter-tags.me.js) et enregistrez
4. Rendez-vous sur [wiki-masters.com](https://www.wiki-masters.com) — le script s'active automatiquement

### Focntionnalités

[`wiki-masterbetter-tags.me.js`](./wiki-masterbetter-tags.me.js) est un script autonome, à partager avec ceux qui ne veulent pas tout le reste : il ne contient que l'**étiquetage en masse** de la collection (avec la modale « Gérer les étiquettes » élargie) et les trois interrupteurs de la page « Marché » (« Mise de départ », « Atténuer possédées », « Masquer possédées »). Il s'installe de la même façon (étapes 1 à 4 ci-dessus), sans dépendance externe. Ne l'installez pas en même temps que le script complet : les deux ajouteraient les mêmes éléments. Les réglages (termes, ordre, interrupteurs) sont les mêmes que dans le script complet.
