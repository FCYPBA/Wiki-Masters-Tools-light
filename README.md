
# 📝 Description

Un script local Tampermonkey qui ajoute une couche d'ajustements de confort, de petites automatisations sur [wiki-masters.com](https://www.wiki-masters.com).

# 🚀 Installation

1. Installez [Tampermonkey](https://www.tampermonkey.net/) (ou un gestionnaire de scripts local compatible) dans votre navigateur
2. Ouvrez le tableau de bord de Tampermonkey et créez un nouveau script
3. Collez le contenu de [`wiki-masters-lighttool.me.js`](./wiki-masters-lighttool.me.js) et enregistrez
4. Rendez-vous sur [wiki-masters.com](https://www.wiki-masters.com) — le script s'active automatiquement

# Fonctionnalités

[`wiki-masters-lighttool.me.js`](./wiki-masters-lighttool.me.js) est un script autonome avec les possibilités suivantes

### MTG 
Etiquetage en masse de vos cartes non etiquetées, un [tutorial](./tutorial/etiquetage-en-masse.md) est disponible 

### Pages du marché 
Ajout de trois bouton filtrant la liste affichée, permettant de masquer ( ou de réduire la visibilité) des cartes déjà en notre possession. Et un autre bouton permettant de masquer les cartes qui ont déjà reçu des enchères
